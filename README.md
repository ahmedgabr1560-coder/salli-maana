# صلِّ معنا

موقع إسلامي شامل لمواقيت الصلاة والأذان والقبلة والقرآن والأذكار.

## المميزات

- **مواقيت الصلاة** دقيقة حسب موقعك (طريقة الهيئة المصرية)
- **عد تنازلي** للصلاة القادمة
- **أذان حقيقي** بأصوات متعددة (مكة، المدينة، مصر، الأقصى، وديع اليمني)
- **تنبيهات** عند حلول وقت الصلاة
- **صفحة أذان كاملة** بشكل برامج المؤذن الإلكترونية
- **اتجاه القبلة** مع بوصلة
- **التقويم الهجري**
- **أذكار** الصباح والمساء
- **مسبحة إلكترونية**
- **القرآن الكريم** (استماع)
- **أسماء الله الحسنى** مع معانيها

## الاستخدام

افتح الموقع واسمح بتحديد الموقع، ثم فعّل التنبيهات واختر صوت الأذان.

جعله الله في ميزان حسناتكم 🤲
